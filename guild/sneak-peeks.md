Since the beginning, CatWeb’s scripting system was never designed for heavy use. It was intended for simple tasks, was slow, and wasn’t built with optimization as a priority. In fact, scripting was originally considered a secondary feature that users didn’t need in order to create a site. It was built to make a button or two interactive, maybe play some music, create simple games and interactions, and other basic uses. However, you all have pushed scripting to its limits, created amazing stuff, and made scripting a core part of CatWeb.

We’ve stuck with the same scripting system until now. That changes as we rewrite the scripting system from the ground up and introduce **Script Compilation**: a system that first compiles a script into something that can be efficiently executed, instead of running directly from the raw code blocks. We've built this system with optimization as a priority so your scripts can run as fast as possible.

We're also removing the **action limit**: compiled scripts will run as fast as your CPU can handle without affecting frame rate, and in the future, will allow us to implement more features and increase limits that a fixed action limit didn't allow for. Below's a comparison on how fast the legacy interpreter can change text vs Script Compilation.

We'll be sharing more information, and hope we can release an early access form soon for those interested in trying Script Compilation at launch. Stay tuned!

@sneak peeks

A few days ago, we released a sneak peek showing the removal of the Object Limit. Today, we'll be releasing more details on this and how limits will work on CatWeb going forward.

**We are removing the Object Limit for everyone:** The Object Limit, as well as individual event and action limits (which have been tripled) will all be replaced by one limit to the "cost" of the site. This is calculated by the number of elements, styling elements, events and actions in scripts. The limit is designed to be high enough that you should not reach it during regular use.

**What happens if I reach the Cost Limit in my site?**
> You will still be able to edit and collaborate in your site! However, you won't be able to publish it. The Editor will only stop working if you go significantly above the limit.

**What about individual limits?**
> We are tripling all individual limits:
> - **Object Limit**: 100/400 → ∞
> - **Action Limit**: 120 → 360
> - **Event Limit**: 30 → 90

**I have Premium, which increases the Object Limit to 400 for me. Since the Object Limit is being removed, what happens to this benefit?**
> You will still keep all other CatWeb Premium perks, including more pages, 3 included domains, custom themes, and more.
