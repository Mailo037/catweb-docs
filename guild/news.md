# [Action Needed] Remove all chat features from websites by April 30th, 2025
Roblox has announced [changes to their community standards](<https://devforum.roblox.com/t/migrate-to-textchatservice-removing-support-for-legacy-chat-and-custom-chat-systems/3237100>) regarding chat features. These changes affect CatWeb creators.

- **What would be considered a chat feature?**
> Anything that allows users to communicate to other users via custom messages is considered a chat feature. View the full list [here](<https://devforum.roblox.com/t/migrate-to-textchatservice-removing-support-for-legacy-chat-and-custom-chat-systems/3237100#:~:text=Nov%201%2C%202024%5D-,How%20are%20chats%20defined%3F,-In%20this%20case>).

- **I have a chat feature in my website. What do I need to do?**
> If your website contains a chat feature as defined above, you'll need to either remove it or make it inaccessible.
> Additionally, you may opt to use pre-set messages, as they are not be affected by this rule.

- **What if I don't remove or make my chat feature(s) inaccessible by April 30th?**
> Your site may be limited from using broadcasts.
> New rules specifically addressing these changes will be implemented in CatWeb, effective April 30th.

- **What if my site is limited from using broadcasts?**
> You'll be able to appeal. More information will be available later on.

- **Why don't you just migrate to TextChatService?**
> TextChatService doesn’t support cross-server communication, which broadcasts depend on. It is standard that websites are cross-server.
> Using one server would conflict with other features and confuse users.

- **Will these changes be permanent?**
> We are fortunate that Roblox will support [cross-server communication for TextChatService in the future](<https://devforum.roblox.com/t/migrate-to-textchatservice-removing-support-for-legacy-chat-and-custom-chat-systems/3237100/395>). Please stay tuned!

We will soon release an in-game announcement about these changes.

# CatWeb's new direction for updates

Previously, all changes would be pushed to everyone, immediately. Additionally, a new change could be made without a new version number. This could result in game-breaking bugs, including breaking the entire scripting system (sorry about that)
I hope the following changes will make versions more straight-forward and reduce issues that occur after release of updates.

Starting Samstag, 19. April 2025:
- A 4th number will be introduced to versions for minor patches.
- Patch numbers (those in `catweb://settings/about`) will be discontinued.
- Every change will result in a new version and be posted to #changelogs.
- **Features and updates will more often be rolled out.**

Starting now:
- We will stop prominently showing Version Numbers in announcements & other places. You'll still be able to see them in #changelogs and `catweb://settings/about`.

# [Action Needed] Follow new preset chat rules by April 26th, 2026
Roblox has announced new guidelines for preset chat systems ([DevForum Post](<https://devforum.roblox.com/t/march-26-2026-an-update-on-our-age-check-to-chat-fast-follow-roadmap/4539685>), [Documentation](<https://create.roblox.com/docs/chat/preset-system-guidelines>)). These changes affect how and when you can implement preset chat features.

Starting on April 26th:
- Presets must be used to express gameplay intent, not dialog. General chat websites or websites where the only purpose is to enable communication will not be allowed.

- **Messages must:**
  - Be relevant to the current game mode or scenario
  - Avoid open-ended or socially exploratory language
  - Ideally expire quickly or lose relevance outside the moment

- **And must not:**
  - Include slang that could carry hidden or evolving meanings
  - Reference real-world contact, identity, or relationships
  - Involve emotional manipulation, social pressure, or content that would violate Roblox's Community Standards

- Preset systems must not gain meaning when combined, repeated, or sequenced. They should be tied to the current context and lose relevance outside the moment. If players can use the wheel to "say anything, just slower," the design is not permitted.

- **You will be required to:**
  - Not incorporate any end marks or terminal punctuation, such as exclamation marks, question marks, or periods
  - Broadcast presets as a string, so they are automatically filtered
  - Have a rate-limit and only allow one message every 10 seconds
  - Limit the number of presets to 12 or less
