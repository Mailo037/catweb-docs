AI Protocol Integration

AI models, agents, and external scripts can submit CatWeb JSON. The response returns either { success: true, image: "data:..." } or { success: false, errors: [...] }.

1. HTTP API (Local Server / Microservice)
curl -X POST http://localhost:3000/render \
  -H "Content-Type: application/json" \
  -d '{"json": [...] }'
2. Web URL Protocol (GitHub Pages)
https://mailo037.github.io/catweb-docs/?json=<encoded_json>&render=image
# or via Base64 hash:
https://mailo037.github.io/catweb-docs/#data=<base64_json>
3. Window postMessage (Iframes & Automations)
window.postMessage({ type: 'catweb:render', json: siteJson }, '*');
window.addEventListener('message', (e) => {
  if (e.data.type === 'catweb:render_result') {
    if (e.data.success) console.log('Image:', e.data.image);
    else console.error('Errors:', e.data.errors);
  }
});
